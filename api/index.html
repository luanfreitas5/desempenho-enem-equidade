    Dados¶

    Download idempotente dos microdados do ENEM (INEP) com cache local.

    Os arquivos brutos vão para data/bronze/raw/<ano>/ e nunca são modificados. Um manifest.json por ano registra URL, tamanho e SHA-256 do CSV; se o CSV e o manifest coincidem, o download é pulado (execução idempotente).

    Modelos e avaliação¶

    Regressão linear de referência (OLS, statsmodels) sobre o questionário em one-hot.

    LinearBaseline ¶

    Regressão linear de referência com variáveis categóricas em one-hot.

    Cada resposta do questionário vira um conjunto de indicadoras (a primeira categoria é a referência). O ajuste é OLS; os intervalos de confiança dos coeficientes usam erros-padrão robustos à heterocedasticidade (HC1).

    Parameters:

    Name Type Description Default
    feature_names Sequence[str]

    Nomes das colunas de X (na mesma ordem), usados nos coeficientes.

    		 required

    Examples:

    >>> model = LinearBaseline(["Q001"])
>>> X = np.array([["A"], ["B"], ["A"], ["B"]], dtype=object)
>>> model.fit(X, np.array([1.0, 2.0, 1.0, 2.0])).predict(X).round(1).tolist()
[1.0, 2.0, 1.0, 2.0]

    Compara desempenho e erro do modelo entre grupos, com intervalos de confiança.

    Parameters:

    Name Type Description Default
    y_true ndarray

    Notas observadas.

    		 required
    y_pred ndarray

    Notas previstas (conjunto de teste).

    		 required
    groups ndarray

    Grupo de cada linha (por exemplo, a faixa de renda).

    		 required
    attribute str

    Nome do atributo analisado (aparece nas tabelas).

    		 required
    reference_group str

    Grupo de referência das diferenças.

    		 required
    n_bootstrap int

    Número de réplicas bootstrap.

    		 required
    confidence_level float

    Nível de confiança dos intervalos.

    		 required
    min_group_size int

    Grupos menores que isto são omitidos (IC instável).

    		 required
    seed int

    Semente base do bootstrap.

    		 required

    Returns:

    Type Description
    tuple[DataFrame, DataFrame]

    (metrics, gaps). metrics tem uma linha por grupo com n, mean_score, mean_error (viés), mae, rmse e r2, cada um com _low/_high. gaps traz as diferenças grupo - referência em nota média, viés, MAE e RMSE, com IC e o indicador significant (IC exclui zero).
    Notes

    Os IC são do tipo percentil sobre reamostragem das linhas; as réplicas de grupos distintos são independentes, então a diferença das réplicas gera o IC da diferença. O R² por grupo não é comparável entre grupos com variâncias diferentes de nota; prefira MAE/RMSE e o viés.

    Examples:

    >>> metrics, gaps = analyze_group_equity(
...     y, pred, income, "income_group", "Mais de 6 SM", 500, 0.95, 100, 42
... )
